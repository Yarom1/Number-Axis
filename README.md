# ציר המספרים

אפליקציית ווב לתרגול ספירה וחשבון על ציר מספרים, לילדים בכיתה ב'.

## הפעלה
אין צורך בהתקנה: קבצים סטטיים בלבד (`index.html`, `style.css`, `app.js`).
- מקומית: `python3 -m http.server` ואז לפתוח את `http://localhost:8000`.
- אפשר לפרסם ב-GitHub Pages ולהוסיף למסך הבית בטאבלט או בטלפון.

שמירת המסך דלוק (Screen Wake Lock) עובדת רק בכתובת מאובטחת (`https://` או `localhost`).

## איך משתמשים
- לוחצים על מספר כלשהו כדי להתחיל, ואחריו על המספר הסמוך: למעלה (חיבור) או למטה (חיסור).
- כל קפיצה מצוירת כקשת עם מספר הקפיצה, ולמעלה מוצג התרגיל (למשל `5 + 3 = 8`).
- לחיצה שלא לפי הסדר משמיעה צליל עדין ומסמנת את המספר הנכון הבא.
- "צעד אחורה" מבטל קפיצה אחת, ו"ניקוי" מחזיר למצב ההתחלתי.
- ⚙️ לבחירת אורך הציר (ברירת מחדל 1–20, כולל טווחים עם מספרים שליליים), 🔊 להשתקת הצלילים.
